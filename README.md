# 🍔 Foodify – Online Food Ordering Web Application

Foodify is a full-stack web application designed to provide a convenient online food ordering experience. Users can explore restaurants, 
browse food menus, add items to their cart, place orders, and manage their profiles through a user-friendly interface.

The project is developed using Java web technologies with MySQL for database management, implementing a structured backend using Servlets, 
JSP, JDBC, and DAO architecture.

## ✨ Features

- 🔐 User Registration & Login
- 🔒 Secure password hashing using BCrypt
- 🍽️ Browse restaurants
- 📋 View restaurant menus
- 🛒 Add items to cart and manage quantities
- 💳 Checkout and place orders
- 📦 View order history
- 👤 User profile management
- 🎁 Unique referral code generation
- 📱 Responsive user interface
- 🗄️ MySQL database integration

## 🛠️ Technologies Used

- **Backend:** Java, JSP, Servlets
- **Database:** MySQL
- **Connectivity:** JDBC
- **Architecture:** DAO Pattern
- **Frontend:** HTML, CSS, JavaScript
- **Server:** Apache Tomcat 10
- **IDE:** Eclipse

## 📌 Project Objective

The objective of Foodify is to develop a real-world web application that demonstrates Java web development concepts, 
database connectivity, session management, CRUD operations, MVC-based request handling, and integration of frontend and backend components.
